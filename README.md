# Classification du dataset Iris - Projet Machine Learning

## Objectif
Ce projet implémente un modèle d’apprentissage supervisé permettant de classifier des fleurs Iris en trois espèces différentes à partir de leurs caractéristiques morphologiques.

## Jeu de données
Le dataset Iris (fourni par scikit-learn) contient 150 échantillons décrits par 4 variables :
- Longueur du sépale
- Largeur du sépale
- Longueur du pétale
- Largeur du pétale

## Méthodologie
- Séparation des données en ensemble d’entraînement (80%) et de test (20%)
- Normalisation des données avec StandardScaler
- Entraînement d’un modèle de régression logistique
- Évaluation via l’accuracy et le classification report

## Résultats
Le modèle atteint une précision de 100% sur l’ensemble de test.
